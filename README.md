# Ridga-cli 🚀

**Ridga-cli** — это удобный консольный установщик приложений для операционных систем macOS и Windows. Проект автоматизирует рутинный процесс настройки рабочего окружения, позволяя разворачивать необходимые программы через терминал с помощью конфигурационных файлов.

Официальный сайт проекта: [timoniki.github.io/Ridga-site](https://timoniki.github.io/Ridga-site)

---

## 📌 Основные возможности

* **Кроссплатформенность:** Поддержка скриптов автоматизации как для macOS (`installer.sh`), так и структуры для Windows (`apps_win.json`).
* **Быстрый старт:** Развертывание пула программ одной командой.
